About this policy

This policy describes DevPulse, an Azure DevOps Services client for macOS, iOS and iPadOS developed by Chrominsky (Bartosz Chrominski), and this product website.

Connections to Microsoft

DevPulse connects directly to the Azure DevOps Services organization you select, and sends the authenticated requests needed to retrieve projects, pipelines, execution data, logs and work items. Saving a work item or uploading an attachment sends that content to your organization. Microsoft processes these requests under its own terms and privacy practices.

Microsoft Entra authentication uses Microsoft's MSAL SDK and the system sign-in. The MSAL 2.16.0 source privacy manifest declares name, email address, other contact information, customer support content, user identifiers, device identifiers, other diagnostic data and phone number for app functionality. All are declared as not used for tracking. DevPulse also sends work item fields, attachment content and relationship changes that you explicitly save to your selected organization.

DevPulse has no developer-operated application backend, advertising integration, or analytics SDK. That does not mean that Microsoft or Apple collects no data.

Credentials on your device

Personal access tokens are stored in the Keychain, scoped to one organization. Each connection profile keeps its own token. Microsoft Entra tokens are managed by MSAL's own Keychain cache. Local preferences hold your connection configuration, profiles, selections and filters. The app does not keep pipeline history or task logs as an offline database, and downloaded or exported files are saved only when you choose to save them.

Sign Out removes the active profile's local authentication and restoration state. It does not revoke a personal access token at Microsoft, and it does not sign you out of your web browser. Revoke a token in Azure DevOps when it should no longer be usable. Azure DevOps organization data is managed by that organization's own policies.

The widget

Widgets read a bounded display cache in the app's shared container. The cache holds pipeline and run identifiers, display names, status, stage names and timestamps. It contains no credentials and no task log content. It stays available after the app quits, and its age is displayed visibly.

iCloud settings

When iCloud settings are available, selected preferences, scoped pins, Work Items defaults, your organization and project choices, and connection profile display metadata (profile names, organization names and accent colors) use Apple's iCloud key-value storage for your Apple Account. Organization and project identifiers and pin labels are part of these preferences.

Credentials, authentication settings, account identifiers, the active profile, the widget cache, loaded API results and editor drafts are not included. Synchronization depends on your Apple Account, your iCloud settings, and Apple's service availability.

You can manage Apple Account and iCloud settings through the operating system.

This website

This is a static website hosted on GitHub Pages. It uses no analytics, no advertising, no cookies, no contact forms, and no third-party font services. Fonts and images are served from this domain. The only script switches the illustration between its Cards and ASCII views and stores nothing. GitHub may process technical information, including IP addresses, to provide and secure its hosting service. See the GitHub General Privacy Statement.

Support and contact

For support and privacy questions, use the GitHub issue forms for this repository. If you contact us through GitHub Issues, we can see the information you submit, and GitHub processes that information under its own policies. Issues are public, so do not post private documents or sensitive personal information.

Changes

If the product's data practices change, this policy will be updated with a new effective date. The November 5, 2026 version adds connection profiles: each profile keeps its own token on the device, and profile names, organization names and accent colors synchronize through iCloud.
